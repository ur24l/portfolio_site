Personal project · AI + n8nRunning daily

AI Tech News Briefing with n8n and Groq

Two n8n workflows that read tech news, use an LLM to pick the important stories, and send me one clean email every morning at 9:00 AM IST — plus an alert only when something really big happens.

Problem
I wanted to follow AI, chips and India tech news without opening dozens of sites or getting lots of emails.
What I built
  • Daily briefing: reads 4 news feeds, removes duplicates, and asks an LLM to choose and summarise 8–12 stories in one email.
  • Breaking alert: checks news every 30 minutes and emails only if a story scores 10/10. It remembers what it sent, so no repeats.
  • Backup model: if the main model (GPT OSS 120B) fails or hits a rate limit, it switches to the smaller GPT OSS 20B.
  • Email design: HTML built with tables so it looks right in Outlook and Gmail.
What I learned
Asking an LLM for a fixed JSON format, handling API errors and rate limits, scheduling with cron, and how hard email HTML is in Outlook.

05 — Learning log

Notes from what I'm learning

Short notes I keep while learning. Filter by topic.

  • AI & LLMs

    Plan for the AI API to fail

    Rate limits and outages happen. In my news project, if the main model fails, n8n switches to a smaller backup model so the email still goes out.

  • n8n

    A webhook is just a URL that waits

    A webhook node gives you a link. When a form sends data to it, the workflow starts. Test with the test URL first, then switch to the production URL.

  • Odoo

    CRM pipeline = stages + leads

    Each lead moves through stages like New → Qualified → Won. Custom fields help the team capture the details they really need.

  • AI & LLMs

    LLMs predict text — so check the output

    An LLM gives the most likely answer, not always the correct one. In automation, add simple checks before you trust what it returns.

  • AI & LLMs

    Clear prompts give better results

    Say who the model is helping, give an example of the answer you want, and ask for a fixed format like JSON when a workflow needs to read it.

  • n8n

    Clean the data before it reaches the CRM

    Trim spaces, fix email case and check for missing fields first. A small cleaning step saves a lot of fixing later.

  • Odoo

    Odoo has an API for almost everything

    Records like leads and contacts can be created from outside Odoo through its API. That is how tools like n8n connect to it.
